검증 현황

계좌 발급 전에 확인할 수 있는 것은 전부 자동 검증해 두었습니다. python scripts/selftest.py 한 번으로 아래가 모두 다시 돌아갑니다.

    계좌 발급 후 할 일

    코드 수정은 없습니다. .env 값만 바꾸고 순서대로 확인하면 됩니다.

    1. 키 입력

      USE_MOCK_MODE=false, AppKey·Secret·계좌번호·HTS ID를 채웁니다. 모의투자 계정 유량은 초당 2건이므로 REST_RATE_LIMIT=2를 유지합니다.

    2. 연결 점검

      python main.py --health-only — 토큰 발급, 시세 조회, 잔고 조회 세 단계가 모두 통과해야 합니다.

    3. 무주문 리허설

      DRY_RUN=true로 10분 돌립니다. 주문 직전까지 전 과정이 실행되고 전송만 생략되므로, 로그의 주문 내용을 눈으로 확인할 수 있습니다.

    4. 실매매 시작

      DRY_RUN=false 후 python main.py. 실데이터가 쌓이면 scripts/train_model.py --source data/cache로 재학습합니다.
